# Monthly Expenses

A personal monthly expense-tracking web app based on the supplied **Monthly expenses.ods** spreadsheet.

## Features
- Dashboard for monthly income, planned costs, transactions and projected savings
- Editable fixed and variable budget categories
- Monthly expense and income transaction tracking
- Annual bills and monthly reserve planning
- Manually updated accounts and savings balances
- JSON export and import of complete data backups

## GitHub Pages
Open repository **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, set **main** and **/(root)**, then Save.

Site: https://naikea.github.io/Monthly-expenses/

## Privacy
The app uses browser localStorage. Transactions, balances and income settings are stored only in the browser where they are entered, **not in the public GitHub repository**. There is no sync between browsers or devices. Export backups regularly. Do not upload private backup files to the repository.

## Spreadsheet caveats
The source income of €4,437 is a reference, not necessarily current income. Update it in Settings. Default budgets are not historical transactions. Review possible overlap between monthly and annual Radio items. Some annual dates are reference/approximate dates.
